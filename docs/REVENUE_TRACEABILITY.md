# 収益トレーサビリティ Ver.0.1

## 目的

Project千人将が関与した任務について、売上だけでなく経費、作業時間、
利益まで記録し、どの任務が経済的な成果につながったか追跡できるようにする。

## 最初に記録する情報

- 関連する任務
- 売上・成果の説明
- 売上額
- 経費
- 利益（売上額から経費を引いて自動計算）
- 作業時間（分）
- 発生日
- 補足

## データの関係

任務1件に対して、収益記録を複数件登録できる。

例：

    任務：note記事を制作する
    ├ 売上記録：記事販売 1,500円
    ├ 売上記録：追加販売 1,000円
    └ 経費記録：画像素材 500円

任務を削除しても収益記録は残し、関連する任務IDだけを未設定にする。
これは過去の売上・経費を経営データとして保持するためである。

## 実装順

1. Neonへrevenue_recordsテーブルを追加
2. Javaから収益記録を登録・取得
3. Web画面に収益入力フォームを追加
4. 売上・経費・利益・作業時間を集計
5. AI将軍が収益実績を参照できるようにする
